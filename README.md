# 实验08：软件运行监控与可观测性平台
## 项目说明
本项目基于开源监控指标标准，使用Streamlit搭建轻量可观测性Dashboard，实现对Web服务CPU、内存、请求流量、p95延迟和服务状态的实时监控，支持模拟高负载与服务宕机异常实验。
## 使用开源项目版本
- Prometheus 指标模型（Counter/Gauge/Histogram）
- Streamlit 1.65.0 可视化框架
- psutil 7.0.0 进程资源采集
## 功能清单
1. 服务状态面板：实时展示服务UP/DOWN状态
2. 进程资源监控：CPU使用率、内存使用率时序曲线
3. 业务流量监控：请求速率实时统计曲线
4. 延迟监控：p95分位延迟时序展示，符合Histogram指标规范
5. 异常模拟：一键触发高负载场景，CPU/延迟/请求速率曲线同步飙升
6. 标签设计：所有指标标签仅保留方法/路由/状态，无高基数风险
## 启动步骤
1. 进入app目录
2. 运行 streamlit run app.py
3. 浏览器自动打开监控Dashboard
## 异常实验记录
- 模拟高负载：CPU从10%飙升至85%，p95延迟从0.1秒升至1.2秒，请求速率从3次/秒升至20次/秒
- 模拟服务宕机：状态面板变红，对应up=0告警触发
